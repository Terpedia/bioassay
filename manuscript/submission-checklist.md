# *Phytochemistry Reviews* submission checklist

This checklist is a gate for submission, not a claim that the current draft is
ready. Items marked `pending` require the final search and author review.

| Item | Status | Evidence / action |
|---|---|---|
| Journal and article type selected | complete | Review target recorded in `JOURNAL_TARGET.md` |
| Title, abstract, and keywords | in progress | Complete abstract after evidence synthesis; add 4–6 keywords |
| Search strategy and dates | complete for initial pass | 9,386 PubMed hits; 7,861 unique candidates; queries and export archived |
| Screening and exclusion log | in progress | Candidate file exists; title/abstract and full-text decisions remain |
| PRISMA-ScR flow summary | pending | Populate only from the screening log |
| Chemical identity crosswalk | in progress | Priority panel exists; extend to all included records |
| Assay-level extraction table | in progress | Expand beyond the initial verified observations |
| Risk/quality or evidence-tier assessment | in progress | Apply protocol tiers at study/assay level |
| Quantitative synthesis | pending | Decide endpoint compatibility before any pooling |
| Figures and tables | in progress | Figure 1 and Table 1 exist; add evidence-domain figure |
| References | pending | Generate from frozen source table; verify every DOI/PMID |
| Data and code availability | in progress | Add persistent repository identifier before submission |
| Funding statement | pending | Confirm with authors |
| Competing interests | pending | Confirm with authors |
| Author contributions | pending | Complete CRediT roles |
| Ethics / consent statements | complete if applicable | Literature/database review; no human or animal intervention by authors |
| Cover letter | draft | [`cover-letter.md`](cover-letter.md) |
| Final PDF and supplementary files | pending | Render and inspect after manuscript freeze |
